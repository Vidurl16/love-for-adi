# Photos go here

1. In Google Photos, select the photos → ⋮ → **Download** (you get a zip).
2. Rename them `01.jpg`, `02.jpg`, … oldest first, and drop them in this folder.
3. List them in `photos` in `../config.js` (same order). Give a photo a `title` + `text`
   to put it on the timeline. Edit the letter and start date there too.
4. Optional: add your song as an `.mp3` here and set `song:` in `config.js`.

Tip: phone photos are huge. Keep each under ~500 KB (about 1600px wide) so the page loads fast.
Any photo that's missing shows a pink placeholder, so the page never looks broken.
